# Nog Eentje Dan — Fase 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** N-weg en dorp met tankstation en café, flitspalen met een boete-opdracht op de telefoon, prestatie-check, nieuw startscherm met instellingen, melding op mobiel, en de game online op Vercel met een README als portfoliopagina.

**Architecture:** Het wegennet krijgt expliciete wegsoorten (`kind`) en wordt in `scripts/generate-roads.ts` uitgebreid; verkeer, zones en opdrachten werken daardoor vanzelf op de nieuwe wegen. Nieuwe spelregels (flitsdetectie, boete, dorpsindeling, vakken, instellingen, apparaatcheck) zijn pure modules met Vitest-tests; weergave (3D, DOM, Web Audio) blijft in dunne lagen die `game/Simulation.ts` en `main.ts` verbinden.

**Tech Stack:** bestaande stack (Vite 8, TypeScript strict, Three.js 0.187, Rapier compat 0.21, Vitest 5 + jsdom). Eén nieuwe devDependency: `@resvg/resvg-js` (alleen voor het genereren van `og.png`, Task 9).

**Spec:** `docs/superpowers/specs/2026-11-08-fase-3-design.md` (plus `2026-11-08-fase-2-design.md` en de hoofdspec `2026-11-08-scroll-rij-game-design.md`)
