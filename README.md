# Nog Eentje Dan

Satirische rij-game: scroll op Swiep, drink een biertje, rij door. Dit is precies waarom je dit nooit in het echt doet.

```bash
npm install
npm run dev      # ontwikkelen (voeg ?debug toe voor FPS-teller en toetsen 1-4 voor promillage)
npm test         # unit tests
npm run build    # statische build in dist/
```

Fase 1 (MVP): centrum + ringweg, verkeer, telefoon-feed, bier, schade, eindscherm en lokale highscore.

Fase 2: opdrachten op de telefoon (chat, like, bestemming), sixpack met bijvullen bij supermarkt of feestje,
stoplichten met een bonus voor door rood rijden, kruispunt-reservering, invoegen en rijstrookwissel op de ring,
voetgangers op zebrapaden, botsende lantaarnpalen en bomen, en gegenereerd geluid (M = geluid aan/uit).
Eigen geluiden: zie `public/sounds/README.txt`.
